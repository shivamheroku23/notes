## 2. 📚 Core Definitions &amp; Full Forms

1. **Ratio (अनुपात):**  
   Comparison of two quantities of **same kind** in the form **a : b**  
   - Example: 2 : 3 (for money, marks, etc.)  
   - 2 : 3 means: for every 2 parts of A, there are 3 parts of B.

2. **Proportion (समानुपात):**  
   Equality of two ratios.  
   - a : b = c : d  
   - Also written as \( \frac{a}{b} = \frac{c}{d} \)

3. **Continued Proportion:**  
   If a : b = b : c, then a, b, c are in continued proportion.

4. **Equivalent Ratios:**  
   Ratios that represent same relation.  
   - 2 : 3 = 4 : 6 = 10 : 15 (multiplying/dividing by same number).

5. **Compound Ratio:**  
   Ratio formed by combining two or more ratios.  
   - If A : B = 2 : 3 and B : C = 4 : 5  
   - Then A : C = (2/3) × (4/5) = 8/15 → 8 : 15

6. **Direct Proportion (प्रत्यक्ष समानुपात):**  
   If one quantity increases, the other also increases in same ratio.  
   - Example: Cost ∝ Quantity (double quantity → double cost).

7. **Inverse Proportion (व्युत्क्रम समानुपात):**  
   If one quantity increases, the other decreases such that **product is constant**.  
   - Example: Time ∝ 1/Speed (double speed → half time).

8. **Unitary Method:**  
   Find value of 1 unit, then multiply to get value of required units.

## 3. 🧠 Deep Logic &amp; Theory

### 3.1 Why Ratios Work

If A : B = 2 : 3, it means:

\[
\frac{A}{B} = \frac{2}{3} \Rightarrow A = \frac{2}{3}B
\]

But actual values could be:

- A = 20, B = 30 (multiply both by 10)  
- A = 40, B = 60 (multiply both by 20)

So, **ratio fixes relationship, not actual magnitude**.  
We can write:

\[
A = 2k,\ B = 3k
\]

for some positive k (called **ratio multiplier**).

### 3.2 Proportion – Cross Multiplication Logic

If:

\[
\frac{a}{b} = \frac{c}{d}
\Rightarrow ad = bc
\]

This gives the powerful **“product of extremes = product of means”** rule.

Used in:

- Scale conversion  
- Word problems where 3 quantities given, 4th missing.

### 3.3 Direct vs Inverse Proportion Logic

1. **Direct:**

- More workers → more work done in same time.  
- More quantity → higher cost (same rate).

Mathematically:
\[
\frac{x_1}{x_2} = \frac{y_1}{y_2}
\]

2. **Inverse:**

- More workers → less time required for same work.  
- More speed → less time.

Mathematically:
\[
x_1 y_1 = x_2 y_2
\Rightarrow \frac{x_1}{x_2} = \frac{y_2}{y_1}
\]

### 3.4 Ratio, Fraction, Percentage – One Triangle

- Ratio a : b → Fraction for A = a/(a + b)  
- Convert to %: \(\frac{a}{a + b} \times 100\%\)

Example: A : B = 2 : 3  
- A share = 2/5 → 40%  
- B share = 3/5 → 60%

## 4. ⚡ Algorithms / Step-wise Templates

### 4.1 Template 1 – Converting Ratio to Actual Numbers (Easy)

**Use when:** ratio + total given.

**Steps:**

1. Sum of ratio = a + b (+ c + …).  
2. 1 part = Total / (a + b + …).  
3. Actual values = ratio × 1 part.

**Pros:** Very simple.  
**Cons:** Slightly slow for mental-only.

---

### 4.2 Template 2 – Ratio Multiplier (k-Method) (Moderate)

**Use when:** relationship given but no total; equations needed.

**Idea:**  
Given A : B = 2 : 3 → A = 2k, B = 3k.

**Steps:**

1. Express all related quantities in terms of k.  
2. Use given equation (difference/total) to find k.  
3. Back-substitute.

**Pros:** Very powerful in **age, salary, partnership** type questions.  
**Cons:** Beginners may find symbol-heavy.

---

### 4.3 Template 3 – Direct/Inverse Proportion Table (Fast for Work &amp; Speed)

**Use when:** “If 4 men take 10 days, how many days for 5 men?” etc.

1. Write a 2-row table of quantity vs effect.  
2. Check if change is direct or inverse.  
3. Apply:

- Direct: \( \frac{x_1}{x_2} = \frac{y_1}{y_2} \)  
- Inverse: \( x_1 y_1 = x_2 y_2 \)

**Pros:** Very fast when practiced.  
**Cons:** Needs clarity about direct vs inverse.

---

### 4.4 Template 4 – Mixing Ratios (Advanced / Mains)

**Use when:** multiple ratios overlapping (A : B and B : C, etc.)

**Steps:**

1. Make common middle term equal by LCM.  
2. Multiply both ratios accordingly.  
3. Read off combined ratio.

**Example:**

A : B = 2 : 3  
B : C = 4 : 5  

Make B same: LCM of 3 and 4 = 12  
→ A : B = 8 : 12  
→ B : C = 12 : 15  
So A : B : C = 8 : 12 : 15

**Pros:** Crucial in **age** and **partnership** problems.  
**Cons:** Slightly time-consuming without practice.

## 5. 📝 Practice Questions Section

### 5.1 Easy Level (Prelims)

---

#### Q1.  
Divide ₹900 between A and B in the ratio **2 : 3**.

**Method 1 – Ratio Sum Method**

Sum of parts = 2 + 3 = 5  
1 part = 900 / 5 = 180  

A = 2 × 180 = 360  
B = 3 × 180 = 540  

**Method 2 – Fraction Method**

A’s share = (2/5) × 900 = 360  
B’s share = (3/5) × 900 = 540  

**Time:** 20–30 sec.

**Analysis:**  
- Classic “divide in ratio” pattern.  
- Trap: Using 2/3 × 900 directly (forgetting sum in denominator).

---

#### Q2.  
The ratio of two numbers is **4 : 7**. If the sum is 132, find the numbers.

**Method 1 – Ratio Sum**

Sum of parts = 4 + 7 = 11  
1 part = 132 / 11 = 12  

Numbers:  
4 × 12 = 48, 7 × 12 = 84

**Method 2 – k-Method**

Let numbers = 4k, 7k  

\[
4k + 7k = 132
\Rightarrow 11k = 132 \Rightarrow k = 12
\]

So numbers = 48, 84.

**Analysis:**  
- Pattern: sum + ratio → direct.

---

#### Q3.  
If A : B = 3 : 5, find A : (A + B).

**Method 1 – Assign Values**

Let A = 3, B = 5  
A + B = 8  

A : (A + B) = 3 : 8

**Method 2 – Fraction Logic**

A / (A + B) = 3 / (3 + 5) = 3/8 → ratio 3 : 8.

**Time:** 15–20 sec.

---

#### Q4.  
Two numbers are in the ratio 5 : 7. If each number is increased by 6, the ratio becomes 7 : 9. Find the numbers.

**Method 1 – k-Method**

Let numbers = 5k, 7k  

After increase: (5k + 6) : (7k + 6) = 7 : 9  

\[
\frac{5k + 6}{7k + 6} = \frac{7}{9}
\Rightarrow 9(5k + 6) = 7(7k + 6)
\]

\[
45k + 54 = 49k + 42
\Rightarrow 4k = 12
\Rightarrow k = 3
\]

Numbers = 15, 21.

**Method 2 – Trial via Options**  
(In exam with options, we can reverse-check quickly.)

**Analysis:**  
- Pattern: “ratio after adding same number” → equation.

---

#### Q5.  
If x : y = 2 : 5, find (3x + 2y) : (x + y).

**Method 1 – Assume Values**

Let x = 2, y = 5  

3x + 2y = 6 + 10 = 16  
x + y = 7  

Ratio = 16 : 7.

**Method 2 – General (for symbolic comfort)**

x = 2k, y = 5k  

3x + 2y = 6k + 10k = 16k  
x + y = 7k  

Ratio = 16k : 7k = 16 : 7.

### 5.2 Moderate Level (Pre + Mains Mix)

---

#### Q6.  
Three numbers are in the ratio 2 : 3 : 4. The sum of the smallest and largest numbers is 42. Find the numbers.

**Method 1 – k-Method**

Let numbers = 2k, 3k, 4k  

Smallest + largest = 2k + 4k = 6k = 42  

\[
k = 7
\]

Numbers: 14, 21, 28.

**Method 2 – Ratio Scaling**

2 : 3 : 4 → 2 + 4 = 6 parts → 6 parts = 42 → 1 part = 7 → same result.

**Analysis:**  
- Pattern: linking subset sum to total ratio.

---

#### Q7.  
In a mixture of milk and water, the ratio of milk to water is 7 : 3. If 5 liters of water is added to the 40 liters mixture, the ratio becomes 7 : 4. Find the quantity of milk in the original mixture.

**Method 1 – k-Method on Initial**

Let initial milk = 7k, water = 3k  

Total mixture = 10k  

Given total mixture initially = 40 liters →  
10k = 40 → k = 4  

So milk = 28 L, water = 12 L  

After adding 5 liters water → water = 17 L, milk = 28 L  

New ratio = 28 : 17, which is not 7 : 4.  
This suggests original total is not 40, but 40 is ambiguous. So we correct the question:

> **Revised Q7 (standard pattern):**  
> In a mixture of milk and water, the ratio of milk to water is 7 : 3. If 5 liters of water is added, the ratio becomes 7 : 4. Find the **quantity of milk** in the final mixture.

**Correct Version – Solution**

Let initial milk = 7k, water = 3k  

After adding 5 L water → milk = 7k, water = 3k + 5  

New ratio = 7 : 4  

\[
\frac{7k}{3k + 5} = \frac{7}{4}
\Rightarrow 7k \times 4 = 7(3k + 5)
\Rightarrow 4k = 3k + 5
\Rightarrow k = 5
\]

So milk = 7k = 35 L (constant).  

Final mixture: milk 35 L, water 3×5 + 5 = 20 L → 55 L total.

**Method 2 – Direct Proportion View**

Since milk remains 7 parts, water changes from 3 parts to 4 parts:  
Increment corresponds to 1 part → matches 5 L.  
So 1 part = 5 L → milk = 7 parts = 35 L.

#### Q8.  
The income of A, B, and C are in the ratio 3 : 5 : 7, and their expenditures are in the ratio 6 : 9 : 14. If A saves ₹600 and B saves ₹800, find C’s savings.

**Method 1 – k-Method for Income &amp; Expense**

Let incomes = 3x, 5x, 7x  
Let expenditures = 6y, 9y, 14y  

Savings = Income − Expenditure  

A: 3x − 6y = 600 …(1)  
B: 5x − 9y = 800 …(2)  

Subtract (1) ×5 from (2) ×3 to eliminate x:

(1) ×5 → 15x − 30y = 3000  
(2) ×3 → 15x − 27y = 2400  

Subtract:

\[
(15x - 27y) - (15x - 30y) = 2400 - 3000
\Rightarrow 3y = -600
\Rightarrow y = -200
\]

Negative y arises due to sign orientation; we can instead solve systematically:

From (1):

\[
3x = 600 + 6y \Rightarrow x = 200 + 2y
\]

Substitute into (2):

\[
5(200 + 2y) - 9y = 800
\Rightarrow 1000 + 10y - 9y = 800
\Rightarrow y = -200
\]

This shows we chose inconsistent data. To keep learning smooth, let’s fix the numbers:

> **Revised Q8 (clean data):**  
> The incomes of A, B, and C are in the ratio 3 : 5 : 7 and their expenditures are in the ratio 2 : 3 : 4. If A saves ₹1,000 and B saves ₹2,000, find C’s savings.

**Solution (Revised)**

Income: 3x, 5x, 7x  
Expenditure: 2y, 3y, 4y  

Savings:  
A: 3x − 2y = 1000 …(1)  
B: 5x − 3y = 2000 …(2)  

Multiply (1) by 3, (2) by 2:

(1) ×3 → 9x − 6y = 3000  
(2) ×2 → 10x − 6y = 4000  

Subtract:

\[
x = 1000
\]

From (1):

\[
3(1000) - 2y = 1000
\Rightarrow 3000 - 2y = 1000
\Rightarrow 2y = 2000
\Rightarrow y = 1000
\]

C’s saving:

\[
7x - 4y = 7000 - 4000 = 3000
\]

So **C saves ₹3,000**.

**Method 2 – Try through options (if given)**  
Check one option for C’s saving that satisfies given ratios.

#### Q9.  
If A : B = 2 : 3 and B : C = 4 : 5, find A : B : C.

**Method 1 – Equalising Middle Term**

A : B = 2 : 3  
B : C = 4 : 5  

Make B same: LCM of 3 and 4 = 12  

First ratio ×4 → A : B = 8 : 12  
Second ratio ×3 → B : C = 12 : 15  

So A : B : C = 8 : 12 : 15.

**Method 2 – Fraction product**

B is common:  
A/B = 2/3, B/C = 4/5 → A/C = (2/3)×(4/5) = 8/15  
So A : C = 8 : 15, and B adjusted in between → same.

---

#### Q10.  
If 3A = 4B = 6C, find A : B : C.

**Method 1 – Let Common Value = k**

3A = 4B = 6C = k  

\[
A = \frac{k}{3},\ B = \frac{k}{4},\ C = \frac{k}{6}
\]

Take LCM of denominators (3, 4, 6) = 12  

Multiply each:

A : B : C  
= (k/3) : (k/4) : (k/6)  
= (4k/12) : (3k/12) : (2k/12)  
= 4 : 3 : 2.

**Method 2 – Number Plugging**

Take k = 12 (LCM):  
3A = 12 → A = 4  
4B = 12 → B = 3  
6C = 12 → C = 2  

Ratio = 4 : 3 : 2.

#### Q11.  
The ratio of A’s salary to B’s salary is 5 : 7. After they receive increments of 20% and 10% respectively, the ratio becomes 6 : 7. Find A’s original salary if the total original salary was ₹48,000.

**Method 1 – k-Method with Percentage**

Original salaries:  
A = 5k, B = 7k  

After increment:  
A’ = 1.2 × 5k = 6k  
B’ = 1.1 × 7k = 7.7k  

Given new ratio is 6 : 7:

\[
\frac{6k}{7.7k} = \frac{6}{7} \Rightarrow \frac{6}{7.7} = \frac{6}{7}
\]

This is not consistent (approximation issues). So we tweak question numbers:

> **Revised Q11 (consistent data):**  
> The ratio of A’s salary to B’s salary is 4 : 5. After increases of 25% and 10% respectively, the ratio becomes 5 : 6. If the total original salary was ₹36,000, find A’s original salary.

**Solution**

Original: A = 4k, B = 5k  

After increments:  
A’ = 1.25 × 4k = 5k  
B’ = 1.1 × 5k = 5.5k  

New ratio A’ : B’ = 5k : 5.5k = 10 : 11, but we want 5 : 6.  
So to keep it crisp, we’ll take standard exam pattern:

> **Final Q11 (standard known good pattern):**  
> The ratio of A’s salary to B’s salary is 3 : 4. After an increment of ₹6,000 in each salary, the ratio becomes 9 : 10. Find A’s original salary.

**Final Q11 – Solved**

Let original salaries be 3k and 4k.  

After increment:

A’ = 3k + 6000  
B’ = 4k + 6000  

Given ratio:

\[
\frac{3k + 6000}{4k + 6000} = \frac{9}{10}
\Rightarrow 10(3k + 6000) = 9(4k + 6000)
\]

\[
30k + 60000 = 36k + 54000
\Rightarrow 6k = 6000
\Rightarrow k = 1000
\]

So A’s original salary = 3k = **₹3,000**.

**Method 2 – Difference Method**

New ratio 9 : 10; difference in parts = 1 part.  
Increase is same in both;  
In such patterns, original ratio difference and new ratio difference correlate with actual increments.  
However, here classical difference shortcut is less clean; equation method is safer.

**Analysis:**  
- Pattern: Same increment changes ratio → equation with k.  
- Trap: Treating increments as percentage instead of absolute.

#### Q12.  
The ratio of ages of A, B, and C is 3 : 5 : 7. After 4 years, the ratio of A to C becomes 4 : 7. Find the present ages.

**Method 1 – k-Method**

Current: A = 3k, B = 5k, C = 7k  

After 4 years: A = 3k + 4, C = 7k + 4  

Given:

\[
\frac{3k + 4}{7k + 4} = \frac{4}{7}
\Rightarrow 7(3k + 4) = 4(7k + 4)
\]

\[
21k + 28 = 28k + 16
\Rightarrow 7k = 12
\Rightarrow k = \frac{12}{7}
\]

Present ages:

A = 3k = 36/7 ≈ 5.14 years (not neat).  
Again we adjust to standard test numbers:

> **Revised Q12:**  
> The present ages of A, B, and C are in the ratio 2 : 3 : 4. After 5 years, the ratio of A’s age to C’s age becomes 3 : 5. Find their present ages.

**Solution**

A = 2k, B = 3k, C = 4k  

After 5 years:  
A = 2k + 5, C = 4k + 5  

\[
\frac{2k + 5}{4k + 5} = \frac{3}{5}
\Rightarrow 5(2k + 5) = 3(4k + 5)
\]

\[
10k + 25 = 12k + 15
\Rightarrow 2k = 10
\Rightarrow k = 5
\]

So present ages:  
A = 10, B = 15, C = 20.

#### Q13.  
In a partnership business, A invests ₹20,000 for 12 months, B invests ₹30,000 for 10 months, and C invests ₹40,000 for 6 months. Find the ratio of their profits.

**Method 1 – Money × Time Product**

A: 20,000 × 12 = 240,000  
B: 30,000 × 10 = 300,000  
C: 40,000 × 6 = 240,000  

Profit ratio = 240 : 300 : 240  
Divide by 60 → 4 : 5 : 4.

**Method 2 – Reduce Before Multiplying**

(2 × 12) : (3 × 10) : (4 × 6)  
= 24 : 30 : 24 → 4 : 5 : 4.

**Analysis:**  
- Pattern: partnership via ratio and proportion.  
- Trap: ignoring time factor.

#### Q14.  
Three containers have mixtures of milk and water in ratios 3 : 1, 4 : 1, and 5 : 1 respectively. If equal quantities from each are mixed, what is the ratio of milk to water in the final mixture?

**Method 1 – Let Each Container = 1 Liter**

Container 1: 3/4 L milk, 1/4 L water  
Container 2: 4/5 L milk, 1/5 L water  
Container 3: 5/6 L milk, 1/6 L water  

Milk total:

\[
\frac{3}{4} + \frac{4}{5} + \frac{5}{6}
= \frac{45 + 48 + 50}{60} = \frac{143}{60}
\]

Water total:

\[
\frac{1}{4} + \frac{1}{5} + \frac{1}{6}
= \frac{15 + 12 + 10}{60} = \frac{37}{60}
\]

Ratio milk : water = 143 : 37.

**Method 2 – Use Common Denominator Volume (e.g., 60 units)**  
Same idea but scaled; logic unchanged.

#### Q15.  
In an election between two candidates, 10% of votes were declared invalid. The winning candidate secured 60% of the valid votes and won by 1,800 votes. Find the total number of votes.

**Method 1 – Ratio and Percent Combined**

Let total votes = 100x  

Invalid votes = 10x  
Valid votes = 90x  

Winner gets 60% of valid = 0.6 × 90x = 54x  
Loser gets 36x  

Difference = 54x − 36x = 18x = 1800  

\[
x = 100
\Rightarrow \text{Total votes} = 100x = 100 × 100 = 10,000
\]

**Method 2 – Direct Proportion on Valid Votes**

Let valid votes = V  

Winner’s votes = 0.6V  
Loser’s votes = 0.4V  

Difference = 0.2V = 1800 → V = 9000  

Total votes = 9000 is 90% of total → total = 9000 × 100 / 90 = 10,000.

**Analysis:**  
- Pattern: election problems using % and proportion.  
- Frequently appears in pre and mains.

## 6. 🕳 Common Traps &amp; Mistakes

1. **Adding Instead of Multiplying for Compound Ratios**  
   - Wrong: A : B = 2 : 3, B : C = 4 : 5 → A : C = (2 + 4) : (3 + 5)  
   - Right: A/C = (2/3)×(4/5).

2. **Forgetting Sum of Parts in Division Questions**  
   - A’s share = `(A’s ratio) / (sum of ratios) × total`.

3. **Confusing Direct vs Inverse Proportion**  
   - “More workers, less days” → inverse.  
   - “More quantity, more cost” → direct.

4. **Ignoring Time in Partnership**  
   - Profit ∝ (money × time), not just money.

5. **Using Different Units in Ratios**  
   - Never compare rupees with units, km with hours, etc., directly.

## 7. 📌 Micro-Revision Box

> [!TIP]
> Revise this immediately before mocks involving arithmetic.

- **Basic representation:**  
  - If A : B = a : b → A = ak, B = bk.  
  - Total = (a + b + …)k.

- **Proportion:**  
  - \( \frac{a}{b} = \frac{c}{d} \Rightarrow ad = bc \)  
  - Used for “three known, one unknown” type.

- **Direct proportion:**  
  - \( \frac{x_1}{x_2} = \frac{y_1}{y_2} \)  
  - E.g., cost, quantity, money, marks (same rate).

- **Inverse proportion:**  
  - \( x_1 y_1 = x_2 y_2 \) or \( \frac{x_1}{x_2} = \frac{y_2}{y_1} \)  
  - E.g., speed–time, men–days.

- **Mixing ratios:**  
  - For A : B and B : C:  
    - Equalise B using LCM of middle terms.  
    - Combine to get A : B : C.

- **Part of total:**  
  - If A : B = a : b →  
    - A’s fraction of total = a/(a + b).  
    - A’s % = a/(a + b) × 100.

- **Partnership key:**  
  - Profit share ∝ (investment × time).

- **Election key:**  
  - Valid votes = total × (100 − invalid %)/100.  
  - Margin usually = (difference in % of valid votes) × valid votes.

Use these as **mental flash cards** during last week before exam.
