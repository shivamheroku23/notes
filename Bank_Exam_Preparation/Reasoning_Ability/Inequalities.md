# ⚖️ Inequalities – Symbol Based Reasoning

> 🧠 Is topic mein A, B, C ke beech relations diye hote hain using  
> &gt;, &lt;, ≥, ≤, = and poocha jaata hai ki kaunsa conclusion **definitely** true hai.

---

## 🌟 1. Symbols ka Matlab

- A &gt; B  → A is greater than B  
- A &lt; B  → A is less than B  
- A ≥ B  → A greater than or equal to B  
- A ≤ B  → A less than or equal to B  
- A = B  → A equal to B

---

## 🔗 2. Chain Making

Statements:

```text
A &gt; B, B &gt; C
```

Chain: A &gt; B &gt; C → So A &gt; C and B &gt; C.

Example:

> Statements: A &gt; B, B &gt; C  
> Conclusion: A &gt; C → Definitely true.

---

## 🔁 3. Mixed Symbols

Example:

> A &gt; B, B ≥ C

Then:

- A &gt; B  
- B ≥ C → B either &gt; or = C  
- So A is definitely **greater than C** → A &gt; C

But about B &gt; C? Not sure (could be equal).

---

## ❌ 4. When Relation Not Possible

If directions opposite:

- A &gt; B, C &gt; B → cannot compare A &amp; C (both on same side of B)

So:

- A ? C → no definite relation

---

## 🧪 5. Examples with Questions

### Example 1

Statements:  
1) A &gt; B, B &gt; C, C ≥ D  

Conclusions:  
I. A &gt; C  
II. B &gt; D

Chain: A &gt; B &gt; C ≥ D

- I: A &gt; C → TRUE  
- II: B &gt; D → B &gt; C ≥ D → So B &gt; D → TRUE

✅ Both follow.

---

### Example 2

Statements:  
P ≥ Q, Q &gt; R, R = S  

Conclusions:  
I. P &gt; R  
II. P &gt; S

Chain: P ≥ Q &gt; R = S

From ≥ and &gt; mix:

- P ≥ Q  
- Q &gt; R → So P is **either &gt; or = Q, which is &gt; R**.  
  So P is definitely **&gt; R**?  
  If P = Q and Q &gt; R → P &gt; R.  
  If P &gt; Q &gt; R → P &gt; R.  
  In both cases P &gt; R → TRUE.

Also R = S → So P &gt; S also TRUE.

✅ Both I &amp; II follow.

II. S &gt; R

---

## ✅ Answers (Brief)

### Q1

Chain: A &gt; B ≥ C &gt; D

- A &gt; C → TRUE  
- B &gt; D (since B≥C&gt;D → B&gt;D) → TRUE  

✅ Both follow.

---

### Q2

M ≥ N &gt; O ≥ P

- M ≥ N &gt; O ≥ P → M is **definitely &gt; P** → I TRUE  
- N &gt; O ≥ P → N &gt; P → II TRUE  

✅ Both follow.

---

### Q3

X &gt; Y &gt; Z

- X &gt; Z → TRUE  
- Z &gt; X → FALSE  

✅ Only I follows.

---

### Q4

J ≥ K = L &gt; M

- K &gt; M (since L&gt;M and K=L) → II TRUE  
- J ≥ K &gt; M → J is **definitely &gt; M** → I TRUE  

✅ Both follow.

---

### Q5

P &gt; Q &gt; R, S ≥ Q

- I: P &gt; R → TRUE  
- II: S ≥ Q &gt; R → So S might be =Q (&gt;R) or &gt;Q (&gt;R), in both S&gt;R → TRUE  

✅ Both follow.
