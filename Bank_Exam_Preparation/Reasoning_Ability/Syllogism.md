# 🔁 Syllogism – All / Some / No Type Logic

> 🧠 Syllogism = “Given statements”, us se **definite conclusions** check karna.  
> Bank exams mein bahut favourite topic.

---

## 🌟 1. Basic Terms

Statements usually:

- All A are B  
- Some A are B  
- No A is B  
- Some A are not B

Conclusions:

- Must be **definitely true**, based **only** on statements.

> [!NOTE] 📌  
> Apni general knowledge use **mat** karo (e.g. all dogs are animals).  
> Sirf given statements ke base par answer do.

---

## 🔑 2. Venn Diagram – Simple Idea

We use **circles** to show sets.

### 2.1 “All A are B”

Circle A completely inside circle B:

```text
   _______
  /       \
 /   B     \
|   ___    |
|  / A \   |
 \ \___/  /
  \_____ /
```

Meaning: A ke saare members B ke andar.

---

### 2.2 “Some A are B”

A &amp; B overlap:

```text
   ___      ___
  / A \____/ B \
  \___/    \___/
```

---

### 2.3 “No A is B”

A and B separate:

```text
 ___      ___
/ A \    / B \
\___/    \___/
```

---

## 🧮 3. Quick Rules (Traditional Pattern)

**Type 1: All A are B**

- Definite:
  - Some A are B → TRUE (since all A are B)
  - Some B are A → TRUE (if A exists)
- “Some A are not B” → FALSE
- “All B are A” → **not definite** (may or may not be)

---

**Type 2: No A is B**

- Some A are B → FALSE  
- All A are B → FALSE  
- Some A are not B → TRUE  
- Some B are not A → TRUE

---

**Type 3: Some A are B**

- “Some A are B” → TRUE  
- “Some A are not B” → NOT definite  
- “All A are B” → NOT definite  
- “No A is B” → FALSE

---

## 🧪 4. Basic Examples

### Example 1

Statements:

1. All cats are animals.  
2. Some animals are wild.

Conclusions:

I. Some cats are wild.  
II. All animals are cats.

Check:

- From given, we can’t say cats are wild or not → I not definite.  
- All animals are cats? No, we only know cats ⊂ animals → II false.

✅ Answer: **Neither I nor II follows.**

---

### Example 2

Statements:

1. All A are B.  
2. All B are C.

Conclusions:

I. All A are C.  
II. Some C are A.

Diagram: A ⊂ B ⊂ C

- I: All A are C → TRUE  
- II: Some C are A → TRUE (if A exists)

✅ Both I and II follow.

---

## 🔁 5. “Some A are not B” Concept

When negative conclusion is true?

Example:

Statements:

1. All A are B.  
2. Some B are not C.

Conclusion:

I. Some A are not C.

We know: A ⊂ B, and some B outside C.  
But we **don’t know** whether those B (not C) belong to A or not.  
So “Some A are not C” is **not definite**.

## ✅ Answers (Brief)

### Q1

All pens are books, and **no book** is pencil.

- I: No pen is pencil → TRUE (since pens ⊂ books and books❌pencil)  
- II: Some books are pens → TRUE (pens exist as books)

✅ Both I and II follow.

---

### Q2

Some dogs are cats, all cats are animals.

- I: Some dogs are animals → TRUE (dogs that are cats → animals)  
- II: All animals are cats → FALSE

✅ Only I follows.

---

### Q3

Some A are B, some B are C.

Overlap B–C but we **don’t know** A–C overlap.

- I: Some A are C → Not definite  
- II: Some C are A → Not definite

✅ Neither I nor II follows.

---

### Q4

All cars are buses; some buses are trains.

- I: Some cars are trains → Not definite (those buses which are trains may be non-car buses)  
- II: All trains are buses → Not given → FALSE

✅ Neither I nor II follows.

---

### Q5

No lion is cow; some cows are goats.

- From “Some cows are goats” → those goats (coming from cows) are not lions.  
  So: Some goats are not lions → TRUE.  
- Some lions are goats → impossible: lions not even cows → FALSE.

✅ Only I follows.
