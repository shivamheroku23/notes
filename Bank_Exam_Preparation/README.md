## 4. 12-Week Master Plan (High Level)

This is a **generic integrated plan** assuming:

- You can study **3–4 hours on weekdays**, **6–7 hours on weekends**.
- Target: **Score 90%+ile in Prelims**, **comfortably clear Mains**.

Detailed day-wise planner, micro-goals, and test schedule will be expanded once all topic files are in place.

### Weeks 1–4: Foundation + Speed (Prelims-Oriented)

- **Quant**: Basic arithmetic (Percentage, Ratio, Average, SI/CI, Time & Work, TSD, Simplification, Number Series).  
- **Reasoning**: Inequalities, syllogism, blood relation, direction, basic puzzles.  
- **English**: Grammar basics + short RCs + vocab lists.  
- **GA/Computer**: Start light – 15–20 mins/day.

### Weeks 5–8: Mains-Level Depth

- **Quant**: Full DI, caselets, mixed arithmetic sets, Data Sufficiency, Probability, P&C.  
- **Reasoning**: Big puzzles, caselets, input-output, high-level LR.  
- **English**: Long RCs, para-based questions, vocab-in-context.  
- **GA/Computer**: Daily current affairs + one revision slot.

### Weeks 9–12: Test Mode

- Alt days: **Full-length mock tests** (Prelims or Mains as per stage).  
- Detailed **mock analysis**: error log, time log, topic-wise gap.  
- Heavy revision with **Micro-Revision Boxes** from each topic file.

## 6. How to Use This Repository Effectively

1. **Choose your exam** (IBPS PO / SBI PO / Clerk / RBI Assistant).  
2. Open the corresponding **section folders**:
   - Start with **Quantitative_Aptitude** → basics like Percentage, Ratio, Average.  
   - In parallel, do **English + Reasoning** light practice daily.  
3. For each topic `.md`:
   - Read **🎯 Concept Map** and **📚 Core Definitions** once slowly.  
   - Spend time on **🧠 Deep Logic**, not just formulas.  
   - Practice the **📝 Questions** in exam conditions.  
   - Mark mistakes in a **separate error notebook**.  
4. Use **📌 Micro-Revision Box** for last 7–10 days before exam.  
5. From Week 5 onwards, integrate **full mocks** and **sectional tests**.
