# 💻 Computer Basics – Hardware &amp; Software

> 🧠 Bank exams mein Computer Awareness mostly **basic level** ka hota hai.  
> Agar aap non-technical ho tab bhi ye chapter bahut easy marks de sakta hai.

---

## 🌟 1. What is a Computer?

Computer = Electronic machine that can:

- **Input** data,
- **Process** data,
- **Store** data,
- **Output** information

---

## 🧱 2. Basic Structure – IPO Cycle

```text
Input  →  Processing  →  Output
           ↓
         Storage
```

- **Input** – keyboard, mouse, scanner
- **Processing** – CPU
- **Output** – monitor, printer
- **Storage** – hard disk, SSD, pen drive

---

## 🧮 3. Hardware vs Software

### 🔹 Hardware

- Physical parts you can **see and touch**.
- Example:
  - CPU cabinet, monitor, keyboard, mouse, printer, hard disk, RAM, motherboard.

### 🔹 Software

- Programs / instructions which run in the computer.
- Cannot be touched, only used.
- Types:
  - System software
  - Application software
  - Utility software

---

## 🧠 4. CPU – Central Processing Unit

Called the **“brain”** of the computer.

Main parts:

1. **ALU (Arithmetic Logic Unit)** – performs calculations and logical operations.
2. **CU (Control Unit)** – controls all activities of computer.
3. **Registers** – very small high-speed memory.

---

## 🧠 5. Memory Types – Primary &amp; Secondary

### Primary Memory (Main Memory)

- **RAM (Random Access Memory)**  
  - Temporary storage  
  - Volatile (power off → data lost)  
  - Used to run programs

- **ROM (Read Only Memory)**  
  - Permanent memory  
  - Stores booting instructions (startup program)  
  - Non-volatile

---

### Secondary Memory (Storage Devices)

- Hard Disk
- SSD (Solid State Drive)
- Pen Drive (USB Flash Drive)
- CD/DVD
- Memory Card

> [!TIP] 💡  
> Primary memory = fast but small, volatile.  
> Secondary memory = slower but large, non-volatile.

---

## ⌨️ 6. Input &amp; Output Devices

### Input Devices

- Keyboard
- Mouse
- Scanner
- Microphone
- Webcam
- Joystick

### Output Devices

- Monitor (screen)
- Printer
- Speaker
- Projector

Some are **Input + Output both**: e.g., Touch screen.

---

## 🧩 7. System Software vs Application Software

### System Software

- Helps computer hardware work properly.
- Example:
  - Operating System: Windows, Linux, macOS
  - Device drivers
  - Utility programs

### Application Software

- User-specific tasks:
  - MS Word, Excel, PowerPoint
  - Browsers: Chrome, Firefox
  - Media players, games

## 📝 8. Practice Questions (with Answers)

```text
1)  CPU is also known as:
    A) Brain of computer
    B) Heart of computer
    C) Eye of computer
    D) Memory of computer

2)  Which of the following is a primary memory?
    A) Hard disk
    B) RAM
    C) Pen drive
    D) CD

3)  Which device is an input device?
    A) Monitor
    B) Printer
    C) Keyboard
    D) Speaker

4)  Which type of software is an Operating System?
    A) System software
    B) Application software
    C) Utility software
    D) Malware

5)  Which of the following is a secondary storage device?
    A) RAM
    B) ROM
    C) Hard disk
    D) Register

6)  Which memory is volatile?
    A) ROM
    B) Hard disk
    C) RAM
    D) CD

7)  Which of the following is not hardware?
    A) Mouse
    B) MS Word
    C) Keyboard
    D) Printer

8)  The full form of CPU is:
    A) Central Print Unit
    B) Central Processing Unit
    C) Central Program Unit
    D) Control Processing Unit

9)  Touch screen is:
    A) Only input device
    B) Only output device
    C) Both input and output device
    D) Storage device

10) ROM stores:
    A) Temporary data
    B) Booting instructions
    C) User files
    D) Videos
```

---

### ✅ Answers

1) A – Brain of computer  
2) B – RAM  
3) C – Keyboard  
4) A – System software  
5) C – Hard disk  
6) C – RAM  
7) B – MS Word (software)  
8) B – Central Processing Unit  
9) C – Both input and output device  
10) B – Booting instructions
