## 🕰️ 1. Short History of Computers

### First Generation (1940–1956)

- Technology: **Vacuum tubes**
- Very large, expensive, high electricity usage
- Examples:
  - ENIAC (Electronic Numerical Integrator And Computer)
  - EDVAC

---

### Second Generation (1956–1963)

- Technology: **Transistors**
- Smaller, faster, more reliable than vacuum tubes

---

### Third Generation (1964–1971)

- Technology: **Integrated Circuits (ICs)**
- Many transistors on a single chip
- Faster and more compact

---

### Fourth Generation (1971–Present)

- Technology: **Microprocessors**
- Personal computers (PCs), laptops
- VLSI (Very Large Scale Integration)

---

### Fifth Generation (Present &amp; Beyond)

- Based on **Artificial Intelligence (AI)**, robotics, supercomputers.

---

## 👨‍💻 2. Important People in Computer History

- **Charles Babbage** – “Father of Computer”
  - Designed Analytical Engine
- **Ada Lovelace** – First computer programmer (wrote algorithm for Babbage’s machine)
- **Tim Berners-Lee** – Inventor of the World Wide Web (WWW)

## 📝 4. Practice Questions (with Answers)

```text
1)  Who is known as the Father of Computer?
    A) Tim Berners-Lee
    B) Charles Babbage
    C) Ada Lovelace
    D) Bill Gates

2)  ENIAC is an example of which generation of computers?
    A) First
    B) Second
    C) Third
    D) Fourth

3)  CPU stands for:
    A) Central Print Unit
    B) Central Processing Unit
    C) Central Program Unit
    D) Control Processing Unit

4)  RAM stands for:
    A) Random Access Memory
    B) Read Access Memory
    C) Rapid Access Memory
    D) Run Access Memory

5)  ROM stands for:
    A) Read Only Memory
    B) Random Only Memory
    C) Read Open Memory
    D) Run Only Memory

6)  LAN stands for:
    A) Local Area Network
    B) Large Area Network
    C) Line Access Network
    D) Local Access Node

7)  WWW stands for:
    A) World Wide Web
    B) Wide World Web
    C) Web Wide World
    D) World Web Wide

8)  URL stands for:
    A) Uniform Resource Link
    B) Uniform Resource Locator
    C) Unified Resource Locator
    D) Universal Resource Link

9)  OTP stands for:
    A) One Time Payment
    B) One Time Password
    C) Online Transaction Password
    D) Only Time Password

10) ATM stands for:
     A) All Time Money
     B) Any Time Money
     C) Automated Teller Machine
     D) Auto Transaction Machine
```

---

### ✅ Answers

1) B – Charles Babbage  
2) A – First  
3) B – Central Processing Unit  
4) A – Random Access Memory  
5) A – Read Only Memory  
6) A – Local Area Network  
7) A – World Wide Web  
8) B – Uniform Resource Locator  
9) B – One Time Password  
10) C – Automated Teller Machine
