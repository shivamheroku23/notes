# 🗂️ MS Office – Word, Excel, PowerPoint (Basics for Banks)

> 🧠 MS Office ke basic concepts bank exams mein baar-baar poochhe jaate hain,  
> specially Word, Excel, PowerPoint.

---

## 🌟 1. MS Word – Word Processing

MS Word = Document creation/editing software.

### Common Uses

- Letter writing
- Reports
- Resume/CV
- Notices

### Important Features

- Font style, size, color
- Bold, Italic, Underline
- Alignment: Left, Center, Right, Justify
- Bullets &amp; Numbering
- Spell check &amp; grammar
- Find &amp; Replace
- Header &amp; Footer
- Page Numbering

---

## 📄 2. MS Excel – Spreadsheet

Excel is used for:

- Calculations
- Tables
- Charts
- Data analysis

### Key Concepts

- Workbook – file
- Worksheet – page inside workbook
- Cell – intersection of row &amp; column (e.g., A1, B2)
- Row – horizontal (numbered 1,2,3,…)
- Column – vertical (A,B,C,…)

---

### 2.1 Basic Excel Formulas

All formulas start with `=`

| Purpose          | Formula Example             | Meaning                          |
|------------------|-----------------------------|----------------------------------|
| Addition         | `=A1 + B1`                 | Sum of A1 and B1                |
| Sum Range        | `=SUM(A1:A5)`              | A1 to A5 ka sum                 |
| Average          | `=AVERAGE(A1:A5)`          | A1 to A5 ka average             |
| Maximum          | `=MAX(A1:A5)`              | Highest value                   |
| Minimum          | `=MIN(A1:A5)`              | Lowest value                    |
| Count Numbers    | `=COUNT(A1:A5)`            | Number of numeric cells         |

---

### 2.2 Example – Simple Table

```text
   A      B
1  Item   Amount
2  Pen    10
3  Book   50
4  Bag    200
5  Total  =SUM(B2:B4)
```

B5 cell will show **260**.

## 📽️ 3. MS PowerPoint – Presentation Software

Used for:

- Slides-based presentations
- Seminars
- Training programs

### Key Features

- Slide layouts
- Design templates &amp; themes
- Slide transitions (effect between slides)

## 📝 5. Practice Questions (with Answers)

```text
1)  MS Word is an example of:
    A) Spreadsheet software
    B) Word processing software
    C) Presentation software
    D) Database software

2)  In Excel, the intersection of a row and a column is called:
    A) Field
    B) Cell
    C) Box
    D) Point

3)  In Excel, which formula is used to find the sum of values from A1 to A5?
    A) =ADD(A1:A5)
    B) =SUM(A1:A5)
    C) =TOTAL(A1:A5)
    D) =PLUS(A1:A5)

4)  Shortcut key for Copy is:
    A) Ctrl + X
    B) Ctrl + V
    C) Ctrl + C
    D) Ctrl + Z

5)  MS PowerPoint is used for:
    A) Making presentations
    B) Writing letters
    C) Managing databases
    D) Sending emails

6)  In MS Word, Ctrl + S is used to:
    A) Save a document
    B) Start a slideshow
    C) Select all text
    D) Stop printing

7)  In Excel, to find highest value in a range A1 to A10, we use:
    A) =TOP(A1:A10)
    B) =HIGH(A1:A10)
    C) =MAX(A1:A10)
    D) =LARGE(A1:A10)

8)  A slideshow in PowerPoint is started using:
    A) F1
    B) F5
    C) F2
    D) F10

9)  In Excel, which is a correct cell address?
    A) 1A
    B) A1
    C) AA0
    D) &amp;B

10) MS Excel is mainly used for:
    A) Creating documents
    B) Creating presentations
    C) Creating and managing spreadsheets
    D) Editing videos
```

---

### ✅ Answers

1) B – Word processing software  
2) B – Cell  
3) B – =SUM(A1:A5)  
4) C – Ctrl + C  
5) A – Making presentations  
6) A – Save a document  
7) C – =MAX(A1:A10)  
8) B – F5  
9) B – A1  
10) C – Creating and managing spreadsheets
