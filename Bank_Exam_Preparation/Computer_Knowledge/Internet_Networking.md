# 🌐 Internet &amp; Networking – Banking Exam Basics

> 🧠 Aaj ke digital banking world mein Internet &amp; Networking basics jaana zaroori hai.  
> Exams mein mostly **1-liner conceptual questions** aate hain.

---

## 🌟 1. What is Internet?

- Internet = **network of networks**.
- World-wide system of interconnected computers that communicates using standard protocols (like TCP/IP).

---

## 🖧 2. Network Basics

### Network

2 ya zyada computers connected together to share:

- Data
- Devices (printers)
- Internet

### Types of Networks

- **LAN (Local Area Network)**  
  - Small area: office, building, lab
- **MAN (Metropolitan Area Network)**  
  - City-level network
- **WAN (Wide Area Network)**  
  - Large area: country, world (Internet itself is a WAN)

---

## 🌍 3. IP Address &amp; Domain Name

### IP Address

- Unique address of a device on network.
- Example: `192.168.1.1` (IPv4)

### Domain Name

- Human-readable name of a website:
  - `www.sbi.co.in`, `www.google.com`

Domain Name System (DNS) converts domain names ↔ IP addresses.

---

## 📡 4. Protocols (Rules of Communication)

- **HTTP (HyperText Transfer Protocol)**  
  - For web pages (http://)
- **HTTPS (HTTP Secure)**  
  - HTTP + encryption (secure)
- **FTP (File Transfer Protocol)**  
  - For file transfer
- **SMTP (Simple Mail Transfer Protocol)**  
  - For sending emails
- **POP3 / IMAP**  
  - For receiving emails
- **TCP/IP**  
  - Basic communication protocol of Internet

---

## 📧 5. Email Basics

Email parts:

- Username + domain
- Example: `user@example.com`

Components:

- Inbox, Sent, Drafts, Spam, Trash
- CC (Carbon Copy), BCC (Blind Carbon Copy)

---

## 🔐 6. Cyber Security Basics

### Viruses / Malware

- Virus – malicious program that attaches to files
- Worm – self-replicating program
- Trojan – looks like useful software but harmful
- Ransomware – encrypts files and demands payment

### Antivirus

- Software used to detect and remove malicious programs.

---

### Phishing

- Fraud emails/messages/websites that try to steal personal info:
  - passwords, bank details, OTP, etc.

> [!TIP] 💡  
> Bank **kabhi bhi** phone/WhatsApp/Email par **OTP, PIN, Password** nahi maangta.

---

### Firewall

- Security system that monitors and controls incoming &amp; outgoing network traffic.

---

## 💳 7. Online Banking Security Terms

- **Encryption** – data ko secret code mein convert karna.
- **Two-Factor Authentication (2FA)** – password + OTP or device.
- **SSL / HTTPS** – secure connection (lock symbol in browser).

## 📝 8. Practice Questions (with Answers)

```text
1)  Internet is:
    A) A single computer
    B) A network of networks
    C) A local software
    D) A hardware device

2)  LAN stands for:
    A) Local Area Network
    B) Large Area Network
    C) Line Area Network
    D) Local Access Network

3)  Which of the following is used for sending emails?
    A) HTTP
    B) SMTP
    C) FTP
    D) POP

4)  Which protocol is secure for websites?
    A) HTTP
    B) FTP
    C) HTTPS
    D) SMTP

5)  Which of the following is an example of a web browser?
    A) Windows
    B) Linux
    C) Chrome
    D) MS Word

6)  Full form of IP is:
    A) Internet Path
    B) Internet Protocol
    C) Internal Program
    D) Integrated Process

7)  Phishing is:
    A) Sending bulk emails for ads
    B) Attempt to steal sensitive information
    C) Scanning for viruses
    D) Solving network problems

8)  Antivirus is:
    A) A type of virus
    B) A hardware
    C) A security software
    D) A protocol

9)  Which of the following is not a type of network?
    A) LAN
    B) MAN
    C) PAN
    D) CPU

10) HTTPS indicates:
     A) Encrypted secure connection
     B) Slow connection
     C) Wireless connection
     D) Local network only
```

---

### ✅ Answers

1) B – A network of networks  
2) A – Local Area Network  
3) B – SMTP  
4) C – HTTPS  
5) C – Chrome  
6) B – Internet Protocol  
7) B – Attempt to steal sensitive information  
8) C – A security software  
9) D – CPU (Central Processing Unit, not a network type)  
10) A – Encrypted secure connection
